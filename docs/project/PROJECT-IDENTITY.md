# Project Identity

**Project:** OrangeFox R12.0 Unofficial for POCO X8 Pro (`klee`)  
**Current independent maintainer / release channel:** RakaRizaldy

This repository is intended to stand as an independent `klee` development and release channel.

It does **not** use any previous unofficial maintainer as:
- project branding;
- release authority;
- maintainer identity;
- support channel;
- ownership claim.

Technical history may preserve factual implementation evidence when needed for reproducibility, but that does not establish affiliation with a previous unofficial maintainer.

Upstream OrangeFox, Android, kernel, device-tree, library, and other third-party attribution/licensing are a separate matter. Required upstream credits and license notices should be preserved according to the actual source used.
